# Pesämuna – asennusohje

Pesämuna toimii selaimessa eikä tarvitse sovelluskauppaa tai maksullisia tilejä.

## Nopein kokeilu (yksi laite)
Avaa `index.html` selaimessa. Tiedot tallentuvat sen laitteen selaimeen.

## Tabletille omaksi sovellukseksi (ilmainen julkaisu)
1. Lataa koko kansio ilmaiseen palveluun, esimerkiksi Netlify, Cloudflare Pages tai GitHub Pages. Saat https-osoitteen.
2. Avaa osoite tabletilla.
3. iPad (Safari): Jaa-painike → Lisää Koti-valikkoon.
   Android (Chrome): valikko ⋮ → Asenna sovellus / Lisää aloitusnäytölle.
4. Pesämuna aukeaa nyt omasta kuvakkeestaan koko ruudulle ja toimii myös ilman nettiä.

## Hyvä tietää
- Tiedot (tähdet, potti, profiilit) tallentuvat vain siihen selaimeen ja laitteeseen, jolla sovellusta käytetään. Selaimen tietojen tyhjennys poistaa ne.
- Aikuisten osio avataan pienellä kertolaskulla.
- Raha ei liiku sovelluksessa: se laskee summan ja pitää kirjaa potista.
- Jos päivität tiedostot palveluun, sovellus hakee uuden version, kun laite on verkossa.
